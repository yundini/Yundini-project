# 블로그 오토파일럿

관심분야를 입력하면 **뉴스·인기 블로그 글을 모아 글감을 찾고**, 내가 찍은 **사진·동영상을 AI가 검토해 넣은 블로그 글**을 써 주고,
**미리보기로 확인한 뒤 네이버 블로그에 자동 발행**하는 대시보드예요.

- AI는 `claude -p`(Claude Code)를 사용해요 → API 키 없이 **Claude 구독 요금제(Pro/Max)** 안에서 동작
- 웹 접속·발행은 **Playwright**로 해요 → 없으면 실행할 때 **자동 설치**
- Mac에서 실행하고, **아이패드 Safari로 접속해서** 사용하는 구조예요

## 흐름

1. **새 글 만들기**: 관심분야 + 메모(선택) + 내가 찍은 사진·동영상 업로드
2. **글감 찾기**: 네이버 뉴스(최근 1주)와 블로그 인기 글(최근 1개월)을 모아 AI가 글감 3~5개 추천
3. **글 쓰기**: 글감을 고르면 AI가 사진을 직접 보고 어울리는지 판단한 뒤, 적절한 위치에 배치해서 새 글을 작성
4. **미리보기**: 제목·본문·태그 직접 수정, 또는 "더 짧게" 같은 수정 요청으로 다시 쓰기
5. **발행**: Mac에서 브라우저가 열려 네이버 에디터에 글·사진·동영상·서식을 입력하고 발행 (또는 임시저장만)

## Mac 준비 & 실행

Mac은 프로그램이 실제로 돌아가는 **본체**, 아이패드는 **리모컨**이에요. Mac에서는 아래만 하면 돼요.

1. **Node.js 설치**: https://nodejs.org/ko/download 에서 **LTS 버전 macOS 설치 프로그램(.pkg)** 을 받아 설치 (22 이상)
2. 이 저장소를 Mac에 받기 (GitHub에서 **Code → Download ZIP** 후 압축 풀기, 또는 `git clone`)
3. 폴더 안의 **`start.command` 더블클릭**
   - 처음 열 때 "확인되지 않은 개발자" 경고가 나오면: 파일을 **우클릭 → 열기**

`start.command`가 알아서 해주는 것:

| 단계 | 내용 |
| --- | --- |
| Node.js 확인 | 없거나 버전이 낮으면 설치 페이지를 열어 안내 |
| 패키지 설치 | **Claude Code**(npm 패키지)와 Playwright를 이 폴더 안에 설치 — Claude 앱은 필요 없어요 |
| Claude 로그인 | 로그인이 안 되어 있으면 Claude Code를 열어 줌 → **구독 계정**으로 로그인 후 `/exit` |
| Playwright | 앱이 켜질 때 Chromium까지 자동 설치 |
| 잠자기 방지 | 실행 중에는 Mac이 잠들지 않음 (터미널 창을 닫으면 해제) |

준비가 끝나면 터미널에 **접속 주소**와 **6자리 접속 코드**가 나와요.

```
 접속 주소: http://localhost:3000
            http://192.168.0.12:3000
 접속 코드: 123456
```

> 터미널에서 `npm install && npm start`로 직접 실행해도 돼요.
> `ANTHROPIC_API_KEY`가 설정되어 있어도 이 앱은 그걸 쓰지 않고 구독 로그인을 사용해요.

## 아이패드에서 쓰기

1. Mac과 아이패드를 **같은 와이파이**에 연결
2. 아이패드 Safari에서 `http://192.168.x.x:3000` 접속 → 접속 코드 입력
3. 공유 버튼 → **홈 화면에 추가**하면 앱처럼 쓸 수 있어요
4. 상단 **"네이버 로그인 확인"** → 로그인 필요하면 Mac 브라우저 화면이 아이패드에 보여요.
   화면을 탭해 입력칸을 고르고 아래 입력창으로 아이디·비밀번호를 보내거나, QR 로그인을 쓰세요.
   로그인이 끝나면 **"로그인 완료 확인"**. 세션은 Mac의 `data/naver-profile`에 저장돼 다음부터는 로그인할 필요가 없어요.

> 밖에서도 쓰고 싶다면 Mac과 아이패드에 [Tailscale](https://tailscale.com)을 설치하면 같은 와이파이가 아니어도 접속할 수 있어요.
> `start.command`로 실행하면 실행 중에는 Mac이 잠자기에 들어가지 않아요. 덮개를 닫으면 잠들 수 있으니 열어 두세요.

## 업데이트

대시보드 위쪽의 **"새 버전 있음 · 업데이트"** 버튼을 누르면 GitHub에서 새 버전을 받아 코드만 바꾸고 앱을 자동으로 다시 시작해요.
글·사진·네이버 로그인·접속 코드(`data/`)와 설치된 패키지(`node_modules/`)는 그대로 유지돼요.

- GitHub 저장소가 **공개(Public)** 여야 동작해요.
- `start.command`로 실행했을 때만 자동으로 다시 켜져요.

## 설정 (환경변수, 선택)

| 변수 | 설명 |
| --- | --- |
| `PORT` | 대시보드 포트 (기본 3000) |
| `DASHBOARD_CODE` | 접속 코드 직접 지정 (기본은 자동 생성, `data/access-code.txt`) |
| `CLAUDE_MODEL` | `claude -p`에 쓸 모델 (기본은 Claude Code 기본값) |
| `CLAUDE_BIN` | 다른 위치의 `claude`를 쓰고 싶을 때 (기본은 프로젝트 안에 설치된 것) |

## 알아둘 점

- **네이버 정책**: 네이버는 자동 발행을 공식 지원하지 않아요. 짧은 시간에 많이 발행하면 계정 제한을 받을 수 있으니 하루 몇 개 이내로 쓰세요.
- **원문 베끼기 방지**: AI는 참고 자료를 그대로 옮기지 않고 종합해서 새로 쓰도록 지시되어 있어요. 그래도 발행 전에 미리보기로 꼭 확인하세요.
- **에디터 변경**: 네이버 에디터 화면 구조가 바뀌면 발행 자동화가 실패할 수 있어요. 실패하면 대시보드에 오류 화면 스크린샷 링크가 표시돼요.
- **동영상**: AI는 동영상을 직접 볼 수 없어서, 업로드할 때 적은 설명을 보고 위치를 정해요. 설명을 적어 주면 더 잘 배치해요.
- 데이터(글, 업로드 파일, 로그인 세션)는 모두 Mac의 `data/` 폴더에만 저장되고 git에는 올라가지 않아요.

## 구조

```
src/
  server.js     대시보드 서버 (API, 업로드, 접속 코드)
  setup.js      Playwright/Chromium 자동 설치
  claude.js     claude -p 호출 (구독 요금제)
  browser.js    네이버 로그인 세션 유지 + 아이패드 원격 로그인
  research.js   네이버 뉴스·블로그 수집
  writer.js     글감 추천, 사진 검토, 글쓰기 프롬프트
  format.js     글 → 에디터 붙여넣기용 서식 HTML
  publisher.js  네이버 스마트에디터 입력·발행
public/         대시보드 화면 (아이패드 대응)
```
